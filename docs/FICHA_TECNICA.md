# Fraudio — Ficha técnica / Technical sheet

## Español

**Versión:** 3.5  
**Fecha original de creación:** 12 de septiembre de 2026  
**Creador:** Fraudy Martinez Madruga  
**Género:** Plataformas 2D / Acción  
**Plataformas publicadas:** Navegador web y versión descargable para Windows

### Descripción

Corre, salta y ábrete paso por ocho mundos llenos de enemigos, bloques, pozos, monedas y power-ups. Fraudio combina plataformas 2D de ritmo rápido con tres niveles de dificultad, habilidades temporales, proyectiles y una presentación audiovisual distinta para cada mundo.

### Características principales

- 8 mundos con ambientación y paletas diferenciadas.
- 3 niveles de dificultad.
- Plataformas, bloques, monedas, enemigos y power-ups.
- Música específica por mundo y variaciones de tensión al final del tiempo.
- Efectos de parallax, partículas y animación ambiental.
- Teclado y controles táctiles en la versión web.
- La ficha de la edición de Windows contempla teclado, gamepads compatibles y controles remapeables.

### Requisitos de la edición de Windows

**Mínimo**

- SO: Windows 7 SP1 / Windows 10 / Windows 11
- Procesador: Intel Core i3-4130 o AMD FX-6300
- Memoria: 4 GB RAM
- Gráficos: Intel HD Graphics 4600, AMD Radeon R5 o equivalente compatible con DirectX 11
- DirectX: 11
- Almacenamiento: 700 MB disponibles
- Audio: dispositivo compatible con Windows
- Objetivo orientativo: 1280 × 720 a 30 FPS

**Recomendado**

- SO: Windows 10 / Windows 11 de 64 bits
- Procesador: Intel Core i5-6500 o AMD Ryzen 3 1200
- Memoria: 8 GB RAM
- Gráficos: NVIDIA GeForce GTX 750 Ti, AMD Radeon RX 550 o superior
- DirectX: 11
- Almacenamiento: 1 GB disponible
- Audio: dispositivo compatible con Windows
- Objetivo orientativo: 1920 × 1080 a 60 FPS

### Versión web

La edición online requiere un navegador moderno con soporte para HTML5 Canvas y reproducción de audio. No necesita instalación.

## English

**Version:** 3.5  
**Original creation date:** September 12, 2026  
**Creator:** Fraudy Martinez Madruga  
**Genre:** 2D Platformer / Action  
**Published platforms:** Web browser and downloadable Windows edition

### Description

Run, jump, and fight your way through eight worlds filled with enemies, blocks, pits, coins, and power-ups. Fraudio combines fast 2D platforming with three difficulty levels, temporary abilities, projectiles, and a distinct audiovisual presentation for each world.

### Main features

- 8 worlds with distinct environments and color palettes.
- 3 difficulty levels.
- Platforms, blocks, coins, enemies, and power-ups.
- World-specific music and higher-intensity variations near the end of the timer.
- Parallax, particles, and environmental animation.
- Keyboard and touch controls in the web version.
- The Windows edition technical specification includes keyboard, compatible gamepads, and remappable controls.

### Windows edition requirements

**Minimum**

- OS: Windows 7 SP1 / Windows 10 / Windows 11
- CPU: Intel Core i3-4130 or AMD FX-6300
- Memory: 4 GB RAM
- Graphics: Intel HD Graphics 4600, AMD Radeon R5, or equivalent DirectX 11-compatible GPU
- DirectX: 11
- Storage: 700 MB available
- Audio: Windows-compatible device
- Guideline target: 1280 × 720 at 30 FPS

**Recommended**

- OS: 64-bit Windows 10 / Windows 11
- CPU: Intel Core i5-6500 or AMD Ryzen 3 1200
- Memory: 8 GB RAM
- Graphics: NVIDIA GeForce GTX 750 Ti, AMD Radeon RX 550, or better
- DirectX: 11
- Storage: 1 GB available
- Audio: Windows-compatible device
- Guideline target: 1920 × 1080 at 60 FPS

### Web version

The online edition requires a modern browser with HTML5 Canvas and audio playback support. No installation is required.
